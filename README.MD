# PDF to DOCX Converter

A Python desktop application that converts PDF
documents into editable Word documents.

## Features
- Simple Tkinter graphical interface
- Select PDF files using a file dialog
- Save converted files as DOCX
- Error handling and conversion status

## Technologies
- Python
- Tkinter
- pdf2docx

## Installation

Install Python, then run:

python -m venv .venv
.venv\Scripts\Activate.ps1
cd pdf-to-docx-converter
pip install -r requirements.txt
python pdftodocx.py

## Run the application

python pdftodocx.py
